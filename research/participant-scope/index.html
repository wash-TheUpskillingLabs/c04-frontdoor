    Saving to GitHub

    1. Select Download note (.md). You get participants-scoping.md.
    2. On GitHub, open research/participant-scope/, choose Add file → Upload files, and drop the downloaded file in to replace the old one.
    3. Describe the change in the commit message and commit it, or open a pull request if you want review first.

    If someone else committed a change since you opened this page, select Load a note file… and load the latest file before editing, so you don't overwrite their work.
